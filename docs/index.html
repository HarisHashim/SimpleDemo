3-Tier Full-Stack Architecture

Clean separation of concerns ensuring testability, maintainability, and clean reactive workflows.

FRONTEND LAYER

Standalone Angular UI

Modern Angular component using signals (title = signal('frontend')) and clean lifecycle management.

frontend/src/app/app.ts
CLIENT TRANSPORT

RxJS ApiService

Encapsulates asynchronous HTTP calls via Angular's HttpClient returning typed Observables.

frontend/src/app/api.service.ts
SECURITY & NETWORK

WebMvc CORS Filter

Configures cross-origin resource sharing via WebMvcConfigurer allowing seamless requests from port 4200.

backend/.../config/WebConfig.java
REST API CONTROLLER

HelloController

Handles incoming @GetMapping("/hello") HTTP requests with Constructor-based dependency injection.

backend/.../controller/HelloController.java
SERVICE LAYER

HelloService

Houses domain business logic and delegates greeting data retrieval cleanly from the repository abstraction.

backend/.../service/HelloService.java
PERSISTENCE / DATA

MessageRepository

Encapsulates data access with @Repository annotation, easily extensible to Spring Data JPA or MongoDB.

backend/.../repository/MessageRepository.java

Core Technology Stack

Built with standard enterprise frameworks and reactive developer ergonomics.

SB

Spring Boot Backend

Java 17/21 • Spring Web • Maven
  • Spring MVC REST Controller (@RestController)
  • Spring IoC & Dependency Injection (@Autowired)
  • Global CORS Configuration (WebMvcConfigurer)
  • Maven build tool configuration (pom.xml)
NG

Angular Frontend

TypeScript • Standalone • RxJS
  • Modern standalone architecture (standalone: true)
  • Angular Signals for reactive component state (signal())
  • HttpClient with Observable pattern for API consumption
  • Vite-powered ultra-fast dev server and bundler

Quickstart & Local Execution

Get the backend and frontend up and running locally in under 2 minutes.

# Navigate to backend and run Spring Boot
cd backend
./mvnw spring-boot:run
# Server running at: http://localhost:8080
# Navigate to frontend, install & run
cd frontend
npm install && npm start
# App running at: http://localhost:4200
# Test REST endpoint via curl
curl http://localhost:8080/hello
# Response:
Hello from Spring Boot!
